Programmed by Benjamin "benjibyte" Brinkerhoff 

## About Sapling
As a Computer Science student, I was excited with how open my Linux computer was, allowing me to look inside the OS and how everything worked. Linux was central to SWE, and yet--it didn't have a proper full blown IDE, the way that Windows has with Visual Studio, and MacOS has with Xcode. All Desktop Linux has is Kate Editor, VS Code, and JetBrains IDEs. 

So I settled on JetBrains for a while, and though I respect their hard work--I'd like a solution that doesn't break the bank. Thus, Sapling the *modern* open source IDE was born. It's Linux native, and will also be developed cross platform as well. At first, I will focus on a strong core language stack and universal Flatpak packaging.
